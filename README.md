# Sales Ledger

Sales Ledger is a desktop-based Sales Record System developed using Python and Tkinter.

Features
- Add Sales Records
- Update Sales Records
- Delete Sales Records
- Search Records
- Revenue Analytics
- Category Distribution Charts
- Top Product Analysis
- CSV Export
- JSON Database Storage

Requirements
- Python 3.11+
- Tkinter
- Pillow
- Matplotlib

Install Dependencies

pip install pillow matplotlib

Run

python main.py
